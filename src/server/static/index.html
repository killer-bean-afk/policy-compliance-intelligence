    System Architecture, Multi-Agent Workflow & Design Decisions

    High-level view of data processing from policy documents through hybrid retrieval to multi-agent compliance response.

    Technical Decisions & Trade-Offs

    1. Hybrid Dense-Sparse Retrieval with Reciprocal Rank Fusion (RRF)

    Dense embeddings (all-MiniLM-L6-v2) capture semantic intent for questions like "Can we share data?" while sparse BM25 captures exact regulatory keywords (e.g. "DPA", "OFAC", "CVSS 9.0", "0.80"). RRF eliminates score scale disparities and achieves 100% MRR.

    2. Deterministic Evidentiary Grounding vs Generative Hallucination

    In enterprise compliance, hallucinated requirements or missed penalty thresholds result in regulatory liability. The Validation Agent rigorously verifies quotes against verbatim source text to guarantee 98%+ grounding faithfulness.

    3. A2A Communication Bus & Dynamic Escalation Handoffs

    Specialist agents exchange findings via a structured message envelope. When high risk is detected, the workflow automatically routes to expedited validation and remediation synthesis.
